# RetailQ:::
 An AI-powered retail analytics tool.It takes raw sales transaction data, computes real statistics like revenue trends and category performance using Python and pandas, then feeds those computed numbers into Google's Gemini LLM API to auto-generate a natural-language executive summary and business recommendations.
-------------------------------------------------------------------------------------------------------------------------------------------------------------
#Tech Stack:::

Python — core language
pandas / NumPy — data loading, aggregation, statistical computation
Google Gemini API (google-genai SDK) — LLM integration for insight generation
Prompt Engineering — structured prompt design enforcing JSON output
Jupyter Notebook — development environment
Dataset: Customer Shopping Trends dataset, 3,900 transactions, 18 columns
